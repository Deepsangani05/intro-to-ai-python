# Introduction to AI & Python

A clean, submission-ready project demonstrating the core concepts of Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL), paired with beginner-friendly Python programs.

## Project Deliverables

1. **Interactive Learning Notes Hub (`index.html`)**:
   - A modern, responsive web dashboard explaining the core concepts of AI, ML, and DL.
   - Includes a comparison table, nested diagram, and a live web chatbot simulator matching the Python chatbot logic.
   - **Hosted Live Link**: [https://Deepsangani05.github.io/intro-to-ai-python/](https://Deepsangani05.github.io/intro-to-ai-python/)

2. **Learning Notes Markdown (`learning_notes.md`)**:
   - A portable documentation file covering the theoretical differences in AI/ML/DL, real-world applications, and Python fundamentals. Suitable for direct import into Google Docs or Notion.

3. **Beginner-Friendly Python Programs**:
   - **`variables_and_types.py`**: Explains dynamically-typed variable assignment, arithmetic calculations, data casting, and user inputs.
   - **`loops_and_conditionals.py`**: An interactive number guessing game demonstrating `while` loops, `for` loops, and `if-elif-else` control flows.
   - **`lists_and_data_structures.py`**: Covers creating lists, positive/negative indexing, list slicing, list modification methods, and list comprehensions.
   - **`functions_and_ai_simulator.py`**: A rule-based AI customer support agent simulator demonstrating functions, arguments, default parameters, and docstrings.

## How to Set Up and Run

### 1. Prerequisites
You need Python 3.8+ installed on your computer. If you don't have it, follow the setup guide in [learning_notes.md](learning_notes.md).

### 2. Verify Your Python Installation
Open your terminal (PowerShell, Command Prompt, or terminal emulator) and check:
```bash
python --version
```

### 3. Running the Python Programs
You can run each script directly from the project directory:

#### Variables and Types Demonstration:
```bash
python variables_and_types.py
```

#### Play the Number Guessing Game (Loops & Conditionals):
```bash
python loops_and_conditionals.py
```

#### Lists and Data Structures Practice:
```bash
python lists_and_data_structures.py
```

#### Run the AI Chatbot Simulator (Functions & Custom Logic):
```bash
python functions_and_ai_simulator.py
```
*(Tip: Type words like 'AI', 'ML', 'DL', 'Python', or 'Help' to interact with the bot! Type 'exit' to quit.)*
